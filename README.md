# Portfolio de Simon Paillaud

Mon portfolio de Product Designer, en anglais et en français.

## Ce que contient le dossier

| Fichier ou dossier | Contenu |
| --- | --- |
| `index.html` | La page, en anglais et en français |
| `assets/css/style.css` | Les styles (couleurs, typographies, mise en page) |
| `assets/js/main.js` | Le choix de la langue, la barre de lecture, l'agrandissement des images |
| `assets/images/` | Ma photo et les visuels de l'étude de cas |
| `CLAUDE.md` | Les consignes que Claude Code lit avant de modifier le site |

## Voir le site sur mon ordinateur

Double-cliquer sur `index.html`. Pour forcer une langue, ajouter `#fr` ou `#en` à la fin de l'adresse.

## Changer une photo

**Le plus simple :** remplacer le fichier dans `assets/images/` par une nouvelle image **portant exactement le même nom**.

| Image | Fichier |
| --- | --- |
| Ma photo | `photo-simon.jpg` |
| Accueil du projet | `cas-accueil.jpg` |
| Questionnaire | `cas-questionnaire.jpg` |
| Panier « Ma sélection » | `cas-panier.jpg` |
| Comparateur | `cas-comparateur.jpg` |
| Design system | `cas-design-system.jpg` |

**Avec Claude Code :** ajouter la nouvelle image au dépôt, puis demander par exemple :
« Remplace ma photo de profil par `nouvelle-photo.jpg` » ou « Mets ce nouvel export Figma à la place du visuel du comparateur ».

## Le CV

Le dépôt est public, donc les CV n'y sont pas : ils contiennent mon numéro de téléphone. Les boutons « Recevoir mon CV par e-mail » ouvrent un e-mail de demande, et j'envoie le PDF moi-même.

## Mise en ligne

Le site est publié avec GitHub Pages, depuis la branche `main`. Chaque modification poussée sur `main` met le site à jour en une ou deux minutes.

Le site ne demande pas aux moteurs de recherche de le référencer (`noindex`). Retirer la ligne correspondante dans `index.html` pour qu'il apparaisse sur Google.
